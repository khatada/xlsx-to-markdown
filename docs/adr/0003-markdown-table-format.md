# ADR-0003: テーブル出力形式に GFM テーブルを採用する

## ステータス

採用済み

## コンテキスト

テーブル領域を Markdown に変換する際、以下の形式が候補として挙がった：

| 形式 | 例 |
| --- | --- |
| GFM テーブル (GitHub Flavored Markdown) | `\| A \| B \|` / `\| --- \| --- \|` |
| HTML テーブル | `<table><tr><td>A</td>...` |
| reStructuredText グリッドテーブル | `+---+---+` / `\| A \| B \|` |
| Pandoc パイプテーブル | GFM と同一構文 |

本ライブラリのユースケース：

- GitHub の README や Wiki への貼り付け
- Notion、Confluence などの Markdown 対応ツールへのインポート
- 静的サイトジェネレーター (Docusaurus, VitePress 等) でのレンダリング

## 決定

**GFM (GitHub Flavored Markdown) テーブル**を採用する。

理由：

1. **最広範なサポート**: GitHub、GitLab、Notion、VS Code プレビュー、多くの静的サイトジェネレーターが GFM テーブルをサポートしている
2. **人間が読みやすい**: プレーンテキストとしても意味が伝わる構造
3. **列アライメント**: セパレータ行 (`| --- |`, `| ---: |`, `| :---: |`) で左・右・中央揃えを表現でき、Excel の配置情報を自然にマッピングできる

HTML テーブルは colspan/rowspan でマージセルを正確に表現できるが、可読性が低く、多くの Markdown パーサーでは意図通りにレンダリングされないため不採用とした。

### 採用したセパレータ表現

| Excel の配置 / 内容 | セパレータ |
| --- | --- |
| 左揃え（デフォルト） | `---` |
| 右揃え | `---:` |
| 中央揃え | `:---:` |
| 数値のみの列（自動推論） | `---:` |

### 特殊文字のエスケープ

テーブルセル内の `|` は `\|` に、`\` は `\\` にエスケープする。セル内改行は `<br>` に変換する。

## 結果

- マージセル（colspan/rowspan）を GFM テーブルで完全には表現できない。マージ子セルは空セルとしてレンダリングされる（[ADR-0005](0005-merged-cell-handling.md) 参照）
- 列数が多い場合、GFM テーブルは横に長くなり可読性が下がるが、これは GFM の仕様上の制約として受け入れる
